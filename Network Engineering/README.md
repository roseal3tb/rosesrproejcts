# Glam & Ping
Glam & Ping is an interactive tech-entertainment project that merges networking, technology, and beauty into a dynamic, competitive experience. Designed to foster engaging user interactions, the platform combines creative challenges, fast-paced gameplay, and sleek visual design to deliver an energetic and memorable event for all participants.

# ✨ Features
Interactive Gameplay: Fast-paced challenges designed to maximize user engagement.

Tech meets Beauty: A unique concept blending aesthetics with interactive technology.

Networking Engine: Built to connect participants through competitive and collaborative experiences.

Visually Appealing UI: Modern, vibrant design tailored for an immersive entertainment feel.
