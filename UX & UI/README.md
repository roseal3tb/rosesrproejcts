# Yusur — Hajj & Umrah Experience Design
Yusur is an end-to-end UX/UI design project created to streamline and elevate the pilgrimage experience for Hajj and Umrah pilgrims. By unifying essential services into a single, intuitive platform, Yusur reduces cognitive load, minimizes crowd friction, and provides real-time guidance during spiritual rites.
# 🌟 Key Features & UX Solutions
🗺️ Real-Time Crowd Mapping: Live density maps and traffic updates around key ritual sites (e.g., Mataf, Jamarat) to help pilgrims navigate safely and avoid high-density bottlenecks.
🔄 Smart Tawaf Tracker: An automated counter and visual guide that tracks circumambulation rounds, provides real-time progress indicators, and displays appropriate supplications (Duas) for each lap.
📍 Interactive Service Locator: Quick, accessible discovery of essential on-site resources, including medical stations, hydration points, rest areas, wheelchair assistance, and lost-and-found hubs.
🌐 Multilingual & Accessible Interface: High-contrast design, large touch targets, and visual icon-driven navigation tailored for diverse global demographics and elderly pilgrims under intense weather conditions.
# 🎨 UX/UI Design Process
1. Research & EmpathyPersona Mapping: Developed profiles spanning elderly pilgrims, non-tech-savvy users, and group leaders.
   Pain Point Identification: Identified key anxieties—getting lost, miscounting Tawaf laps, navigating dense crowds, and language barriers.
2. Information Architecture & WireframingSimplified Flow: Designed a low-friction hierarchy prioritizing single-tap access to vital features (Map, Tracker, Help).
   Wireframing: Low-fidelity and high-fidelity wireframes created to test tactile clarity and glanceability under sun glare.
3. Visual Design & PrototypingDesign System: Calm, reassuring color palette paired with high-readability typography optimized for outdoor visibility.
   Interactive Prototypes: Clickable user flows mapping the full journey from arrival to completion of rituals.
